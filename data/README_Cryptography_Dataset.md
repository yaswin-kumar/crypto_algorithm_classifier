
# Cryptography Algorithm Identification Dataset

**Dataset Name:** Cryptography Algorithm Identification Dataset

**Dataset Description:**
This dataset contains processed cryptographic data, crafted for research in identifying cryptographic algorithms based on cipher text data. 
It includes 10,000 tuples of cipher text data, targeting algorithms like RSA, AES, DES, and others, to help develop machine learning models for algorithm identification.

**Dataset Structure:**
Each row in the dataset includes:
- **Cipher Text**: Encrypted text generated using various cryptographic algorithms.
- **Algorithm**: The specific cryptographic algorithm used for encryption (e.g., RSA, AES, DES).

**Use Cases:**
- Algorithm identification and classification in cryptographic research.
- Machine learning and AI applications for cybersecurity and encryption analysis.
- Educational resource for students and researchers in cryptography.
